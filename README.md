Entry for [The Funniest Sick-Day Excuse](https://make.fun/bounty/u-zeroxfive-the-funniest-sick-day-excuse-37423a36) on [make.fun](https://make.fun).

`main.ts` writes a single line — one funny, half-believable sick-day excuse — to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output/entry.txt`), and checks the gate itself: 1 to 200 characters, one line, not only whitespace.

The line:

> Sorry, can't come in — I sneezed so hard I threw my back out, and honestly, if that's not a sign from the universe, I don't know what is.

Run it with Node 22.18 or later:

```sh
node main.ts
```
